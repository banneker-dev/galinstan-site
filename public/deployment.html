The questions a diligence reviewer asks first, answered on the page rather than in the third meeting.

Galinstan is built as software you install and run inside your own perimeter. There is no tenancy and no console on our side.

What leaves. Nothing, by design. The software makes no outbound connection of any kind — not for licensing, not for telemetry, not for model weights, not for updates. It is built to run on a machine with no route to the internet, and it has nothing to reach if it is given one.

What you buy. Galinstan is built to run on hardware you already know how to procure. We size each deployment against named, purchasable machines, measure the figures on the machine rather than model them, and publish the specification rather than quote it on request.

What we are to your register. We license Galinstan annually with support, patches and calibration. Supervisory guidance treats a software licence that carries ongoing support as an ICT service, so we expect to appear in your register of information as a provider. What changes is not the entry. It is that none of your data reaches us, and no part of the analysis depends on us being reachable.

Upgrades. Every version is cut as a signed release: an offline bundle with a checksum for every file and a software bill of materials. It installs with no package index and no network, and the instance never reaches out for it.

Escrow and exit. Every release is built to be deposited — source, bundle and checksums as one versioned artefact. We agree escrow and exit terms in the contract rather than pointing at a policy page.
